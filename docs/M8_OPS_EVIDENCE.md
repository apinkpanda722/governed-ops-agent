## 한계

- (a)는 단위 테스트 코드의 단언을 정리한 증거다. 대상은 가짜·인메모리·로컬 루프백(ASGI)과 임시 로컬 파일이며, 실제 서비스 실행 결과를 추가한 것이 아니다. 실제 Postgres 경쟁은 `make test-outbox-pg`·`make test-m5-pg` (사용자 실행)로 따로 확인한다. 해당 타깃은 이번 step에서 실행하지 않았다.

- `tests/test_m8_ops_evidence_doc.py`는 이 문서와 인용 대상 테스트 파일 6개만 읽으며, 테스트 이름·인용 문자열의 존재·표 구조·한계 칸을 검사한다. 줄 번호는 검사하지 않는다. 사례 절 (b)의 정확성은 이 테스트가 보증하지 않는다. 기록 디렉터리와 평가 데이터에는 의존하지 않는다.
- 표를 작성 뒤 plain text로 한 번 출력하여 열 경계를 확인한다. 렌더 도구는 설치하지 않으며, 사람이 읽는 렌더 확인(스크린샷)은 phase 실행 뒤 조언 세션에서 수행한다.
