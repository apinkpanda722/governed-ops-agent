## 3. 실행 범위

- N2: 공식 구성 v1로 test 40 × 3회(프로세스 3개, 실행마다 새 프로세스).
- N3(v1 참고)는 공식 구성이 v1이므로 N2와 같은 구성의 중복이라 **생략한다**.
- 사람 채점은 test 1회차 30건 층화 표본, Gemini 채점은 사람 채점 해시 커밋 뒤에 한다(기존 절차).
- test 40에 대한 오탐 보고(N2)는 v2 제외 판정에 쓰지 않는다(`hypotheses-m6-redteam-run.md` 7절).
