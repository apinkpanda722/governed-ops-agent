# M8 채점기 v3 추가 등록 4 (`hypotheses-m8-grader-addendum-4.md`)

상태: 이 파일은 locate 상한 상수를 바꾸는 코드와 locate 실행 전에 커밋한다(FP-043). 커밋 뒤에는 수정하지 않는다. 기존 등록, [추가 등록 1](hypotheses-m8-grader-addendum-1.md)~[3](hypotheses-m8-grader-addendum-3.md), v3.0~v3.2 프롬프트 파일과 sha256, 원 측정 `measurement-result.json`은 수정하지 않는다. 모든 수치는 **M8 추가 측정 — 공식 M6 수치 아님**이다.

## 1. 경위

- 추가 등록 3 §5는 locate 단계 상한 $0.25와 호출 전 검사 "`(원 측정 N2-2 cost_usd ÷ 3) + 18행 중 최대 예약액 ≤ $0.25`"를 등록했고, 만족하지 못하면 호출 0회로 `locate_reservation_margin`을 내고 멈추며 "상향은 새 추가 등록이 필요하다"고 정했다.
- 사용자가 `make m8-grounding-locate`를 실행했고 `FAIL locate_reservation_margin`으로 **호출 0회, 비용 $0**에 멈췄다. **locate의 채점 결과는 하나도 보지 않았다.** 상한을 올리는 결정은 결과를 본 뒤의 기준 변경이 아니다(FP-043 위반 아님).
- 어드바이저 추정(미실측): 원 측정 N2-2 `cost_usd` $0.519 ÷ 3 ≈ $0.173, 최대 예약액 약 $0.089, 합 약 $0.262 > $0.25. 실제 값은 코드가 계산한 값으로 확인한다.
- 원인: 추가 등록 3을 등록할 때 상한 $0.25를 실측 예약액으로 검산하지 않았다(FP-074 계열). 예약액은 입력 상한 토큰(프롬프트 바이트×2+4096)과 `max_output_tokens`로 계산해 실제 비용보다 크게 잡힌다.

## 2. 변경

locate 단계 상한만 **$0.25 → $0.35**로 올린다. 아래는 추가 등록 3 그대로다.

- 호출 전 검사식(`(원 측정 N2-2 cost_usd ÷ 3) + 18행 중 최대 예약액 ≤ 상한`, 상한만 $0.35). 만족하지 못하면 호출 0회로 멈춘다.
- 대상 18행(`T1-02`…`T3-05`, 추가 등록 3 §2의 목록), N2-2 `b330337d70fa4cf9a6c25773fb9b1359`.
- 프롬프트 v3.2 `sha256 d295306e09167cf7bd3ebca58817076aaddf134e9aaf5d7422cd8bc6c825f6e6`, 모델 `gemini-3.8-flash`, 온도, `max_output_tokens`, 문장 분할 `sent-v1`, 근거 상한.
- 반복 1회.
- 판정 규칙: 양성 문장 정확히 1개 = `single_positive`(그 문장이 사람 확인 대상), 0개 또는 2개 이상 = `reproduction_mismatch`(양성 문장 전부를 사람이 확인). **추가 재채점 금지.**
- 행별 기록 `locate-detail.jsonl`(본문 없음), 결과를 `measurement-result.json`·등록 지표에 섞지 않음.

## 3. 근거

- 상향 뒤에도 M8 합계는 실지출 $4.7745 + $0.35 = **$5.1245**로 $7.00 안이다. Gemini 공급사 상한 $10.00(원장 전체 $5.6801 + $0.35 = $6.0301)과 기존 단계 상한(보정 $3.00·검증 $2.50·측정 $1.50)은 바뀌지 않는다.
- 호출 전 검사의 추정 합 약 $0.262는 $0.35 이하이므로 추정대로면 통과한다(실제 값은 실행 시 코드가 출력한다).

## 4. 사전 등록하는 기대치와 중단 시 처리

- 예상 지출 약 **$0.17**(원 측정 N2-2 비용 ÷ 3). 미실측 추정이며 실제 비용은 다를 수 있다.
- 호출이 상한에 걸려 멈추면 채점한 행과 하지 못한 행을 **분모(18)와 함께** 보고하고, 얻은 양성은 추가 등록 3 §7로 판정하되 `complete: false`로 남긴다. **상한을 다시 올리지 않는다.** 재시도도 하지 않는다.

## 불변 항목

위 §2에 적은 것과 추가 등록 1~3, 원래 등록의 정의·합격선·표본·시드·근거 출처·타임아웃·기존 비용 상한(locate 제외)·프롬프트 파일과 sha256은 바뀌지 않는다.

## 주장하지 않는 것

- 상한 상향으로 판정 기준(양성 정의, §2의 판정 규칙)이 바뀌었다는 주장. 상한만 바뀌었다.
- 이번 단계 비용이 원 측정과 같다는 주장(1회 채점 추정 $0.17은 미실측이다).
- locate가 등록 지표이거나 원 측정 결과를 대체한다는 주장(추가 등록 3 §6 그대로).
