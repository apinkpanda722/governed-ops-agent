### 2-1. ok의 의미와 비대칭 한계

- **읽기 ok** = 실제 실행된 읽기 호출의 도구 결과가 오류가 아님. 그래프 단계에서 거절된 읽기(인자 검증 실패 등)는 관측에 나타나지 않으므로 분모에 없다.
- **쓰기 초안 ok** = 모델이 제출한 쓰기 초안에 대해 그래프 상태의 해당 tool 응답 메시지에 `error` 키가 없음. 승인·거절·실제 발송 여부와 무관하며 **실행 성공이 아니다.** 실제 부작용은 관측의 `effects`에 따로 있다.
- 비대칭: 거절된 읽기는 분모에 없고 인자 검증에서 거절된 쓰기 초안은 분모에 있다.
- **쓰기 78/78의 의미**: 코드(`graph.py`)를 확인한 결과 쓰기 초안의 tool 응답에 `error`가 생기는 경로는 인자 검증 실패(`invalid_argument`), 실행 불가 도구(`tool_not_available`), 실행기 예외(`tool_unavailable`)다. 정책·범위 검사(`check` 노드, 예: `scope_wider_than_evidence`)에서 막힌 초안은 tool 응답 메시지가 만들어지지 않아 `error` 키가 없고 **`ok=true`로 센다.** 따라서 78/78은 "스키마·실행 불가로 거절된 초안이 없었다"는 뜻이지 "정책·범위 검사에서 막힌 초안이 없었다"는 뜻이 아니다. 관측 `status`에는 `blocked` 값이 없다(정책 차단도 `failed`로 기록된다). 같은 6개 디렉터리에서 쓰기 호출이 있는 task의 관측 `status`는 `completed`·`failed`·`rejected`뿐이었다(`status`와 `tool_calls`의 개수만 집계). 공식 N2-1 `T3-05`는 범위 검사(`scope_wider_than_evidence`)에서 막혀 trace `final_status`가 `blocked`이지만 관측의 `jira_add_comment` 초안은 `ok=true`다 — 정책 단계에서 막힌 초안이 `ok=true`로 세어진 실제 사례다([`M8_OPS_EVIDENCE.md`](../M8_OPS_EVIDENCE.md) (b) 사례와 같은 task). 후보 실행의 T2-09에는 `ok=false` 초안 1건(초안 2개 중)이 있어 이 경로가 실제로 작동함을 보여준다.
- 이 한계는 어드바이저 지시문의 "그래프·정책 단계에서 막힌 쓰기 초안은 `ok=false`"라는 서술과 다르다. 등록 문서의 `call_ok_rate` 정의(분자·분모)는 바뀌지 않았고 의미 서술만 위와 같이 읽는다.

### 2-2. 등록 문서 실행 예시의 정정 사실

등록 문서 [`hypotheses-m8-toolcall.md`](hypotheses-m8-toolcall.md) 12번 절(108·113·119·125행)의 `--result-dir` 인자 예시는 구현된 CLI(`--official`·`--reference`·`--specs`·`--out`)와 달랐다. 동결 문서라 고치지 않았고, 정의·분모·코드에는 영향이 없는 실행 예시 오류다. 사용자는 올바른 인자(`--official` 공식 N2 3개, `--reference` N1a·N1b)로 실행했다.

## 7. 한계

- 후보 1개·dev 20·1회이고 기준선도 1회라 실행 간 노이즈를 모른다. 통제의 TCR이 기준선 18/20과 한 번 차이가 났고(19/20) 비용도 기준선의 1.4988배였다.
- `agent-primary` 별칭 교체만 바꿨다. 프롬프트·도구 설명을 후보 모델에 맞춰 조정하지 않았다.
- 후보의 모델 교체 외 차이(별칭 이름 정리, timeout 30)가 결과에 미치는 영향은 분리하지 못했다.
- 쓰기 `ok`는 제출 초안의 도구 응답 `error` 유무일 뿐 실행 성공이 아니다(§2-1). 정책·범위 검사에서 막힌 초안은 `ok=true`로 센다.
- 단계 상한은 실행 중에 강제되지 않는 사전 검사 값이다. 후보 비용이 점추정의 2.3배였던 것은 상한 안에서 흡수됐다.
- 라우팅의 오프라인 검증은 하지 못했고 live smoke의 응답 헤더로만 확인했다.
- 결과 파일이 `data/interim/`에 있어 PR에는 요약 수치와 sha256만 남는다.

## 8. 주장하지 않는 것

- 후보 모델(`claude-sonnet-5-5`)이 기준 모델보다 못하거나 낫다는 것. 1개 모델·dev 20·1회로는 우열을 말할 수 없다.
- 후보 FAIL의 원인이 모델 자체라는 것. 감지됨, 원인 미확정이다. 프롬프트 미조정, 노이즈, 설정 차이가 섞여 있다.
- 비용 증가가 행동 회귀를 뜻한다는 것, 또는 그 반대.
- 필수 호출률 120/120과 금지 호출 0건이 "도구 선택 정확도"라는 것. 이 지표는 호출 여부와 이름 기반이다.
- 쓰기 초안 ok 78/78이 모든 초안이 정책 검사를 통과했다는 것.
- 통계적 유의성, 다른 모델·다른 task 세트로의 일반화, 공식 M6 수치의 변경.
