# M8 채점기 v3 추가 등록 3 (`hypotheses-m8-grader-addendum-3.md`)

상태: 이 파일은 `locate-positives` 코드와 실행 전에 커밋한다(FP-043). 커밋 뒤에는 수정하지 않는다. 기존 등록([`hypotheses-m8-grader.md`](hypotheses-m8-grader.md)·`citation`·`hallucination`), [추가 등록 1](hypotheses-m8-grader-addendum-1.md)·[2](hypotheses-m8-grader-addendum-2.md), v3.0~v3.2 프롬프트 파일과 sha256, 원 측정 `measurement-result.json`은 수정하지 않는다. 모든 수치는 **M8 추가 측정 — 공식 M6 수치 아님**이다.

## 1. 목적

원 측정(N2-2)에서 채점기가 낸 양성 1문장(1행)이 **어느 행·어느 문장인지** 특정해 "사람 확인 1건"에 쓴다. 원 측정은 행별 기록(`measurement-detail.jsonl`)을 남기지 않아 위치를 알 수 없다. 이 단계는 **위치 확인 전용**이며 **등록 지표가 아니다**. 환각률·양성 개수·κ 등 어떤 등록 값도 이 단계 결과로 바꾸거나 대체하지 않는다.

## 2. 대상

원 측정이 채점한 N2-2(`b330337d70fa4cf9a6c25773fb9b1359`)의 18행이다. `observations.jsonl` 순서(task ID 정렬 순서와 같다)로 앞 18개이며, 제외된 행은 없었다(`excluded` 비어 있음).

`T1-02`, `T1-03`, `T1-04`, `T1-06`, `T1-07`, `T1-09`, `T1-10`, `T2-04`, `T2-05`, `T2-06`, `T2-07`, `T2-08`, `T2-10`, `T2-11`, `T2-12`, `T3-03`, `T3-04`, `T3-05`

구현은 N2-2 observations의 앞 18개가 위 목록과 정확히 같은지 확인하고, 다르면 호출 없이 `measurement_order_mismatch`로 멈춘다.

## 3. 채점 조건

- 프롬프트: `docs/m8-prompts/v3_2.txt`, `sha256 d295306e09167cf7bd3ebca58817076aaddf134e9aaf5d7422cd8bc6c825f6e6`(채택값과 다르면 실행하지 않는다).
- 모델 `gemini-3.8-flash`, 온도, `max_output_tokens`, 문장 분할 규칙 `sent-v1`, 근거 상한(`evidence_max_chars`)은 원 측정과 같다.
- **반복은 1회**다(원 측정은 3회). 양성은 그 1회에서 `unsupported` 또는 `contradicted`인 문장이다.
- 근거는 원 측정과 같은 읽기 전용 복원 DB(`govops_m8_evidence`)에서 읽는다.

## 4. 행별 기록

`data/interim/m8-grounding/locate-detail.jsonl`에 남긴다. task ID, 문장 ID, 라벨, 상태 코드, 비용만 담고 **문장·근거·요청 본문은 넣지 않는다**. 파일은 커밋하지 않는다(`data/interim/`). 이미 있으면 실행하지 않는다(`already_located`).

## 5. 비용

- 새 단계 `locate`의 상한은 **$0.25**이며 M8 합계 $7.00 안에 들어간다(실지출 합 $4.7745 + $0.25 < $7.00). Gemini 공급사 상한 $10.00과 기존 단계 상한(보정 $3.00·검증 $2.50·측정 $1.50)은 바뀌지 않는다.
- 호출당 예약액이 상한을 막지 않는지 **호출 전에** 확인한다. 예약액 = 호출 입력 상한 토큰(프롬프트 바이트×2+4096)과 `max_output_tokens`로 계산한 최대 비용이다. 호출 전 검사: `(원 측정 N2-2의 cost_usd ÷ 3) + 18행 중 최대 예약액 ≤ $0.25`. 만족하지 못하면 **호출 0회로** `locate_reservation_margin`을 내고 멈춘다. 상한을 올려 다시 시도하지 않으며, 상향은 새 추가 등록이 필요하다.
- 상한 도달, 행 실패, 호출 실패가 나도 **재시도하지 않는다**. 얻은 행만 기록하고 `complete: false`로 남긴다.

## 6. 결과의 격리

결과는 `measurement-result.json`이나 등록 지표에 섞지 않는다. 원 측정 값(58/120행, 양성 N2-1 3문장/1행·N2-2 1문장/1행, 비용 $1.447)은 바꾸지 않는다. `recompute-measurement`·`report`의 측정 수치도 이 단계 결과를 읽지 않는다.

## 7. 판정 규칙

양성은 18행의 모든 문장 중 위 §3의 1회 채점에서 양성인 문장이다.

| 양성 문장 수 | 기록 | 사람 확인 대상 |
|---|---|---|
| 정확히 1개 | 위치 특정(원 측정 N2-2 양성과 일치로 본다) | 그 문장 1개 |
| 0개 | **재현 불일치** | (없음) 이 경우 사람 확인으로 넘길 문장이 없다는 사실만 기록한다 |
| 2개 이상 | **재현 불일치** | 양성 문장 **전부** |

- 사전 등록 시점에 양성 문장은 최대 5개일 것으로 본다. 6개 이상이어도 확인 대상을 줄이지 않고 전부 낸다(그 자체를 재현 불일치의 정도로 기록한다).
- 0개일 때 "N2-2 양성 1문장이 사람 확인 없이 사라졌다"고 읽지 않는다. 원 측정의 값은 그대로 두고, 재현 불일치를 결과 문서 한계 절에 적는다.
- **추가 재채점은 하지 않는다.** 판정은 이 1회 결과로만 낸다.
- 사람 확인 결과(`supported` 여부 등)는 이 단계의 산출물이 아니라 결과 문서 §7에 사람이 적는다.

## 8. 재현성 근거 (이 등록의 전제)

- 보정 v3.2 행별 기록(`calibration-detail.jsonl`)의 채점기 양성은 T3-11 s3·s4·s6(3문장/1행)이며, 측정 N2-1의 양성(3문장/1행)과 일치한다.
- N2-2 반복 3회의 양성은 1/1/1문장으로 같았다.
- 둘 다 동일 프롬프트·온도 0에서의 재현이라는 정황이며, 이 단계의 결과를 미리 단정하지 않는다.
