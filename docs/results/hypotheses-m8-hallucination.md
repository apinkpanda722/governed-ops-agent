# M8 환각률 사전 등록 (`hypotheses-m8-hallucination.md`)

상태: **초안(untracked)**. `m8-grading-v3` phase 실행 전에 커밋하고 이후 수정하지 않는다(FP-043). 채점기 검증·표본·합격선·합성 주입은 [`hypotheses-m8-grader.md`](hypotheses-m8-grader.md)를 따른다. 표기는 **M8 추가 측정 — 공식 M6 수치 아님**이다. 에이전트는 바꾸지 않는다.

## 1. 정의

- **채점 대상 문서**: grader §4(발송 본문 우선, 없으면 답변). 완료 안내문("승인된 내용대로 실행했습니다")은 대상이 아니다(이슈 #160을 채점 입력 쪽에서 해결).
- **단위는 결정론 문장**이다([grader §4](hypotheses-m8-grader.md)의 분할 규칙 `sent-v1`). 채점기와 사람이 문장 번호마다 `supported`/`unsupported`/`contradicted`/`not_claim` 중 하나를 단다. 채점기가 주장을 스스로 나누지 않는다.
- **`not_claim` 판단 안내(고정)**: 인사·맺음말, 요청 문장을 되풀이하는 문장, 형식 문장(제목·목록 머리), 부재 진술("찾을 수 없습니다"·"권한이 없어 확인할 수 없습니다"), 승인자 수정 표식 문장(`[승인자 수정]…`), 일반 상식 문장. 결과를 본 뒤 바꾸지 않는다.
- **양성 문장** = `unsupported` 또는 `contradicted`(근거 본문에서 확인되지 않거나 어긋남).
- **환각률(문장 단위)** = 양성 문장 수 / (`not_claim`이 아닌 문장 수).
- **환각률(행 단위)** = 양성 문장이 하나 이상인 행 수 / 채점된 행 수. 두 단위를 **둘 다** 보고한다.
- `no_permission` 유형에서 기록에만 있는 내용을 단정하는 문장은 양성 문장으로 센다("볼 수 없다"는 부재 진술은 `not_claim`).

## 2. 분모와 보고 형식

- 분모: 근거가 있고(`evidence_missing` 제외)·길이 상한 이하이고(`evidence_oversize` 제외)·채점 대상 문서가 있고(`deliverable_empty` 제외)·채점기가 성공한 행. 이 네 가지 제외 건수를 모두 결과 표에 적는다.
- 문장 수(`not_claim` 포함·제외 두 가지)·행 수·유형(T1~T6)별 분모와 행당 문장 수 분포를 함께 보고한다. 비율만 단독으로 쓰지 않는다.
- 반복 3회의 비율은 반복별 계산 뒤 중앙값, 문장 라벨은 최빈 라벨·양성은 2/3 이상(grader §5).
- 대표 수치로 쓰는 조건: grader §10의 `채점기 v3 검증 통과`. 미달·판정 불가이면 **환각률 수치를 주장하지 않고** 검증 진단(κ·탐지율·오탐률·양성 수·원인 진단)만 보고한다.

## 3. 대상 실행

공식 N2 120 실행 중 근거가 확보된 행(측정, grader §11). 검증 표본(보정·held-out)은 검증용이며 측정 분모와 섞지 않는다.

## 4. 보고 문구 규칙

- "환각률 X%"를 쓸 때는 반드시 "채점기 v3 검증 통과(held-out κ = …, 탐지율 …, 오탐률 …)"를 같은 문장 군에 쓴다.
- 합성 주입 탐지율은 쉬운 사례의 상한이라고 쓴다.
- 이 수치는 공식 M6 수치가 아니며 에이전트 개선을 뜻하지 않는다.

## 5. 주장하지 않는 것

- 에이전트가 환각하지 않는다는 주장. 0건은 관측값이지 증명이 아니다.
- 이슈 #159(발송 범위 검사 근거 목록 불일치)의 해소. 이 측정과 무관하다.
- 근거로 쓴 checkpointer 본문이 모델이 본 전부라는 주장(모델 내부 추론·사전 지식은 근거가 아니다).
